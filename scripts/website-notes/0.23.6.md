# Website release notes: 0.23.6

Curated, marketing-altitude copy for raucle.com. `scripts/sync_website.py`
renders this file when the release tag syncs the website, instead of falling
back to first sentences of the engineering changelog. The changelog stays the
engineering record; this file is the only copy that reaches the home page.

## Features

- Demo visitors get read-only views of the Users, SIEM and Config tabs. The demo MCP Scanner tab now renders scanner findings on arrival.
- The Agent Assurance demo gains a Coverage card over this deployment's own gate receipts.
- Receipt signing gains a TEE path backed by hardware attestation. Boot fails closed until an enclave signer is wired.
- Gate chaos mode (off by default) injects named faults that produce signed fault receipts.
- The admin plane accepts optional OIDC/SSO federation, off by default.
- OpenAPI becomes a secondary schema source, and a hot-path bench harness measures p50/p99 on the real production paths.
- See the changelog for the full list.

## What's new

read-only demo operator surfaces, a TEE signer adapter path, gate chaos mode (default-off), OpenAPI as a secondary schema source, a hot-path bench harness, and optional OIDC/SSO federation
