- feat(shadow): live non-enforcing shadow policy evaluation (issue #344 items 8-12, ADR 0010 section 4): after the authoritative decision exists, the same normalized request is offered to a bounded candidate evaluator (`raucle.policy_shadow.ShadowEvaluator`) that applies the candidate policy with the gate's own deterministic rule-matching plus constraint plus approval-threshold machinery; the decision that ships is untouched and rows are metadata-only, carrying candidate and active policy digests, request identity by the receipt input-hash convention, and coverage metadata, never argument values and never denial reasons.
- feat(shadow): bounded by construction: a bounded queue whose overflow sheds shadow work by name (never pushing back on enforcement), one bounded worker, a wall-clock budget per evaluation (over-budget results are dropped and counted), a row-capped artifact, deterministic sampling with counted unsampled requests; worker-stuck, over-budget and exception paths are proven unable to block, delay, mutate or forward the live decision or receipt.
- feat(shadow): shadow results are a distinct evidence family in a dedicated artifact (`kind: shadow_eval`, mode `policy_shadow/v1`), never a signed gate receipt, never an `x_sim` simulation receipt and never present in the receipt store; historical simulation and its signed receipt semantics are untouched (its tests run unchanged).
